# Hajj Health Monitoring Project

## Overview
The Hajj Health Monitoring Project aims to enhance the health and safety of pilgrims during the Hajj pilgrimage through the use of technology and data management.

### Objectives
- Monitor the health conditions of pilgrims
- Provide timely health information
- Ensure a safe environment for all participants

# مشروع مراقبة الصحة للحج

## نظرة عامة
يهدف مشروع مراقبة الصحة للحج إلى تعزيز صحة وسلامة الحجاج خلال رحلة الحج من خلال استخدام التكنولوجيا وإدارة البيانات.

### الأهداف
- مراقبة الحالة الصحية للحجاج
- توفير معلومات صحية في الوقت المناسب
- ضمان بيئة آمنة لجميع المشاركين
